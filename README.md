# ثمانية — محوّل الصوت إلى 8D

تطبيق ويب لمعالجة الصوت بمحرك FFmpeg حقيقي. تُرفع الملفات إلى الخادم مؤقتًا للمعالجة ثم تُحذف بعد إرسال الناتج. يدعم الملفات المحلية وروابط YouTube عبر yt-dlp.

## التشغيل

شغّل المحرك المحلي (يتطلب FFmpeg وyt-dlp في PATH):

```bash
python server.py
```

ثم افتح `http://localhost:4173` في Chrome أو Edge.

## المزايا الحالية

- رفع بالسحب والإفلات أو اختيار الملف
- معاينة فورية مع شكل موجة وموضع تشغيل
- التحكم بسرعة الدوران وعمق الحركة والصدى
- تصدير WAV ستيريو بجودة المصدر
- معالجة محلية تحافظ على خصوصية الملف
- محرك 8D حقيقي: orbit stereo عبر `apulsator`، echo قصير، limiter وEBU loudness normalization
- تنزيل صوت YouTube عبر `yt-dlp --no-playlist`
